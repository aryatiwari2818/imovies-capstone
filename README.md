# IMovies - MERN Stack Capstone Project

An end-to-end movie ticket booking application built using the MERN stack (MongoDB, Express, React, Node.js) and Bootstrap.

## Features
- Movie discovery with genre, language, and search filtering
- Interactive seat selection grid with real-time price calculation
- Simulated payment checkout and booking confirmations
- RESTful API backend handling Auth, Movies, Shows, and Bookings
- Data validation and password encryption via Bcrypt and JWT

## Tech Stack
- **Frontend:** React, React Hooks, Bootstrap
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Authentication & Security:** JSON Web Tokens (JWT), BcryptJS, Express-Rate-Limit
